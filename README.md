PM01E70007 – Examen: Gestión de contactos

Nombre completo: Angely Paulethe Ramos Pinto
Número de cuenta: 322270007

Aplicación Android (Java) para gestionar contactos con persistencia en SQLite, usando arquitectura MVC + DAO.

 Funcionalidades

- Pantalla 1 – Registro: país con código de área, nombre, teléfono, nota e imagen (cámara o galería). Validación con alertas y expresiones regulares.
- Pantalla 2 – Lista: listar, buscar, actualizar, eliminar, compartir y ver imagen.
- Pantalla 3 – Llamar: confirmación con AlertDialog y llamada con ACTION_CALL (permiso CALL_PHONE en tiempo de ejecución).

Las capturas están en la raíz del proyecto.
